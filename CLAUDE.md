# Vegas Strip map

Static site: MapLibre base map with a Three.js (r160) city drawn into the same canvas. No build step.

- Run: `npm start` (http://localhost:8080). Preview config: `.claude/launch.json` → `vegas-map`.
- Test: `npm test` (and `npm run test:drive` for the driving checks).
- Local coordinates are metres: `x` east, `y` up, `z` south. See `landmarks/georeference.mjs`.

## Rebuilding a resort from a reference screenshot

When asked to remake, fix or improve how a building looks (usually against an Apple Maps screenshot),
follow **[docs/landmark-rebuild-playbook.md](docs/landmark-rebuild-playbook.md)** step by step.

- Worked example: `world/tropicana-trio.js` (MGM Grand, Excalibur, New York-New York).
- Shared tools: `world/hero-kit.js` (geometry soup, facade shader modes, light spill, signs, turrets).
- Footprint inspector: `node scripts/dump-footprints.mjs "<name>" --rings`.

Files under `landmarks/vendor/` are regenerated by `npm run import-landmarks`; flag any edits there.
Do not commit or push unless asked.
