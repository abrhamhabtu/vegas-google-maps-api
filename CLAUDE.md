# Vegas Strip map

Static site: MapLibre base map with a Three.js (r160) city drawn into the same canvas. No build step.

- Run: `npm start` (http://localhost:8080). Preview config: `.claude/launch.json` → `vegas-map`.
- Test: `npm test` (and `npm run test:drive` for the driving checks).
- Local coordinates are metres: `x` east, `y` up, `z` south. See `landmarks/georeference.mjs`.

## Rebuilding a resort from a reference screenshot

When asked to remake, fix or improve how a building looks (usually against an Apple Maps screenshot),
follow **[docs/landmark-rebuild-playbook.md](docs/landmark-rebuild-playbook.md)** step by step.

- Worked example: `world/tropicana-trio.js` (MGM Grand, Excalibur, New York-New York).
- Shared tools: `world/hero-kit.js` (geometry soup, facade shader modes, light spill, signs, turrets).
- Footprint inspector: `node scripts/dump-footprints.mjs "<name>" --rings`.

## Improving roads from map references

1. Pick one corridor or intersection. Use the supplied map screenshots and aerial views as needed to check lane counts and direction, turn pockets, dividers, crosswalks, and crossing levels. For one-way streets and access drives, check bike lanes, sidewalks, parking bays, and entry and exit directions where they apply.
2. Use the Google raster tiles for visual context and the OpenStreetMap-based snapshot in `landmarks/footprints.json` for georeferenced geometry. Record curb positions and lane widths as estimates when measured geometry is unavailable.
3. Build pavement, median edges, and lane paint from the same lane graph and intersection plan that the AV simulator follows. Reuse `boundaryAt` and `boundaryLine` for tapers and lane markings. Keep medians clear of turn connectors and verify the level of pedestrian crossings.
4. Blend the corridor's asphalt and paint into the surrounding streets. Check the result in Day, Sunset, and Night. Save a Places preset and capture the before and after at the same camera angle and theme.
5. Run `npm test` and `npm run test:drive`. Exercise the affected lane movements, including dedicated turns, with Zoox, Waymo, and Tesla.

The Flamingo pass in `world/flamingo-streets.mjs` defines the local pavement blend and approach geometry scope. The shared road renderer is in `landmarks/vendor/map/roads.js`.

Files under `landmarks/vendor/` are regenerated by `npm run import-landmarks`; flag any edits there.
